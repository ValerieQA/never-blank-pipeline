<!--

WHAT AN ITEM IS, AND IS NOT. An exemplar is a piece of Never Blank writing a
Writer can learn register and form from — `K-EXM-01`: "References beat abstract
rules for register and form; ceiling at 2–5 examples; selection by text type, not
by topic." A research note *about* form is not one. The readability research in
this directory (`article_readability_research.md`, `12_—_Структура_статьи…`) is
the source the architecture was written from and is deliberately **not** indexed
here. #338's first attempt indexed it and was blocked for exactly that reason.

COVERAGE. This library currently covers **linkedin / post only**, from the one
body of genuine Never Blank prose the repository holds. There is no item for
wix / article or for facebook, instagram, threads or telegram, because no
published Never Blank text for those surfaces is stored here — the published
index keeps each article's hook and echo but not its body. S-11 therefore
attaches no exemplar for those destinations, which is the supported state, not a
fault. See the README for exactly what editorial input would close the gap.

IDs are `REF-` and three digits, and they are permanent. Adding an item means
adding a row with the next unused number; nothing is renumbered, because an
exemplar an earlier run recorded still names the item it named then. A withdrawn
item has its row removed and its number is not reused.

`Take` says what a Writer may carry across; `Do not copy` says what belongs to
that text and to nothing else — an example handed over without the second note is
a template.
