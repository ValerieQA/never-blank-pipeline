# No near-exact republication

## Rule
A text that is a near-exact republication of something already published on
that destination is not published again.

## Criterion
Code compares the text's digest and its near-duplicate profile — shingles and
n-grams — with the publication index for this client and destination. A digest
match is a duplicate outright. A near-duplicate is one whose overlap leaves no
new reader-facing content: the same claims in the same order with the wording
moved about.

## Enforces
`K-DIV-06`: republishing a near-exact text on the same destination is a
duplicate under platform rules (tier 1). S-14 re-confirms the same thing from
the other side, through the idempotency authority.
