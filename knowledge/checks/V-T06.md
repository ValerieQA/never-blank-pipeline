# No phrase or construction the client forbids

## Rule
The text contains none of the phrases the Client Contract forbids, and executes
none of the construction types it forbids.

## Criterion
Code matches the contract's forbidden list against the text, case-insensitively
and whitespace-insensitively, as the client's own list declares it is matched.
The execution call answers the part a string match cannot: does a segment
execute a forbidden construction type — a rhetorical question standing in for a
statement, a "not X but Y" reversal, a closing that addresses the reader —
however it is worded? Each finding names the entry or the construction type, so
the edit is an edit and not a rewrite.

## Enforces
The client's tier-2 prohibitions, through map §9.2 V-T06. For Never Blank those
are `clients/never_blank/lists/machine_tells.md` and the rules in
`clients/never_blank/rules/`; the Engine matches, and what is on the list is the
client's own policy.
