# Which tie-breaker keeps deciding

## Rule
The distribution of the tie-breakers that decided strategy selection is worth
reporting. It is never a reason to block, edit or replan anything.

## Criterion
Code counts, over the fingerprints of a period, which tie-breaker of map §7.3
was the deciding one in each StrategySelection. A distribution collapsed onto
one tie-breaker says the earlier ones are not separating candidates — the
choice is being made by cost or by portfolio pressure rather than by evidence.
The count is a report to the keeper.

## Enforces
Nothing. Map §7.3 and §9.2 V-S07: the order of the tie-breakers is a decision
somebody made, and this is how it is checked against what actually happens.
