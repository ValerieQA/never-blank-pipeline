# Every fact in the text comes from the Evidence Core

## Rule
Every figure, name, date and link in the text is in the Evidence Core, and is
quoted as the core has it. No claim is asserted more strongly than the ceiling
the strength ladder gives its evidence.

## Criterion
Code reconciles the text with the core: each figure, proper name, date and link
is matched against a core entry, and the match is exact rather than
approximate. The truth call answers the part code cannot: does the text state
that entry as the entry has it, and does the wording assert at or below the
level the ladder allows for that evidence? An item with no entry fails; an item
stated differently from its entry fails; a level-2 case written as "across the
industry" fails.

## Enforces
I-03 — the core is the only source of fact — and the ceiling half of AD-10.
Map §9.2 V-T01.

## Route

| a fact is not in the core, branch **removable** | S-13 → S-12 | phrasing_or_removable_fact | L_edit | skip_publication |
| a fact is not in the core, branch **load-bearing** | S-13 → S-08 | structural_or_load_bearing_fault | L_strategy | skip_destination |
| a claim is asserted above the ceiling its evidence reaches | S-13 → S-12 | phrasing_or_removable_fact | L_edit | skip_publication |

## Branch criterion
Code locates the unsupported item and the plan elements — thesis, promise, move,
opening — that reference the text span. The truth call answers one question: can
each of those elements still be executed with only core material? Yes →
`removable`, and the Writer edits against the same approved plan. No →
`load-bearing`: the plan required material the core does not hold, and the plan
owns the fault. When uncertain, the plan branch. A decision error is never
charged to the Writer by default (Step 2 §5.3).
