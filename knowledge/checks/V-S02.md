# How long the reader waits for something specific

## Rule
The number of words before the first specific, and the position of the first
piece of evidence, are worth recording. Neither is a reason to block, edit or
replan anything.

## Criterion
Code counts, per text: words before the first figure, named party, date or
quoted fact; the position of the first evidence reference as a fraction of the
text; and how much abstraction precedes it. The numbers are recorded as
measurements. The map marks this check **not validated**: nobody has shown yet
which values matter, so no value may be turned into a threshold without an
owner's approval (I-12), and none is proposed here.

## Enforces
Nothing. It is one of the measurements the portfolio needs before any claim
about openings can rest on evidence rather than on taste.
