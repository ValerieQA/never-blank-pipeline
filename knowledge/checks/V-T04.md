# No invented links and no invented sources

## Rule
Every link and every named source in the text is one the Evidence Core holds,
with the URL the core has.

## Criterion
Code extracts every URL and every source attribution from the text and matches
each against the core's source observations. The comparison is on the URL as
written, not on the domain: a real publication with a URL nobody can open is an
invented link. Nothing here is left to a model — a fabricated citation is the
one failure a model is least able to see in its own output.

## Enforces
I-03 at its most concrete, through map §9.2 V-T04. A source the reader cannot
reach is the failure the whole Evidence Core exists to make impossible.
