# Construction types associated with generated text

## Rule
A hypothetical reader scene ("Suppose you…", "Imagine…"), a "not X but Y"
reversal, and a question standing where the ending should be are worth
noticing. None of them is a reason to block, edit or replan anything.

## Criterion
Code finds the openers and the reversal shapes it can match as strings. The
execution call answers what the strings miss: does this segment put the reader
into a scene that did not happen, or define a thing only by what it is not?
Each finding is recorded with the segment, and the count goes into the
portfolio signal. No threshold decides anything (I-12).

## Enforces
Nothing. It supports `K-OPN-03b` — a hypothetical reader scene is a candidate
pattern, tier 3 — and `K-VOI-03`, that AI patterns come from structure rather
than from words. A client that wants one of these forbidden outright says so in
its own tier-2 rule, where V-T06 enforces it.
