# Global English

## Rule
An idiom, or an American term used without explanation, is worth noticing where
the audience reads English as a second language. It is never a reason to block,
edit or replan anything.

## Criterion
Code matches the idiom and regional-term lists it holds. The execution call
answers the rest: would a reader with the Audience Profile's `english_level`
have to know this expression, or a US-specific institution, to follow the
sentence? A term explained in place is not a finding. The check runs where the
profile says the audience is global; where it says native, its findings are
recorded and carry no weight.

## Enforces
Nothing. Map §9.2 V-S09. The audience attribute it reads is
`audience english_level`, which is client setup material, so a client with a
native audience simply reads these hints differently.
