# The same idea said twice

## Rule
An idea the text states more than once, in different words, is worth noticing.
It is never a reason to block, edit or replan anything.

## Criterion
Code computes the pairwise similarity of the text's segments and surfaces the
close pairs. The execution call answers the question similarity cannot: do
these two passages advance the reader, or do they say one thing twice? A
deliberate return — the Echo to the opening — is not a repetition, and the call
is told so explicitly.

## Enforces
Nothing. It supports the structural half of `K-VOI-03`: a text that repeats
itself reads as generated even when every sentence is defensible.
