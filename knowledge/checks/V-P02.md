# The plan promises no more than the boundary admits

## Rule
The plan's promise is contained in the Interpretation Boundary: it makes no more
points than the boundary has admissible interpretations, and it carries none
that the boundary recorded as inadmissible.

## Criterion
Code compares two lists. Every point the plan promises resolves to an
interpretation id in the current E-09 version's `admissible` set, and the count
of promised points is no greater than the count of that set. An id in
`inadmissible`, at the version the plan was decided against, fails outright.
No model is asked: both lists are the run's own records.

## Enforces
I-05, through map §9.1 V-P02. This is where a plan that over-promises is
stopped, before any prose is paid for — the Ramp "3 things" case in map §13 B,
where the boundary held two interpretations.
