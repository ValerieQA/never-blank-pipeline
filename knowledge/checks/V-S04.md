# Paragraphs and sentences that are all the same length

## Rule
Uniform paragraph and sentence length across a text is worth recording. It is
never a reason to block, edit or replan anything.

## Criterion
Code records the distribution: paragraph lengths, sentence lengths, and the
spread of each. What is recorded is the distribution itself, not a verdict on
it. The map marks this check **not validated**, so no value here becomes a
threshold without an owner's approval (I-12), and none is proposed.

## Enforces
Nothing. It feeds the text profile in the fingerprint (E-16), where the
portfolio can eventually say whether the spread means anything.
