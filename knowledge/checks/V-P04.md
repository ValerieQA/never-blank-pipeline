# The plan complies with the Client Contract and with hard platform policy

## Rule
The plan meets every tier-2 rule of the Client Contract in force for this
destination, and every tier-1 hard platform rule the destination has.

## Criterion
Code applies the rules that are lookups: forbidden phrases, fixed slots the
contract decides, length and hashtag policy, and each tier-1 `K-DST-*` rule for
this destination. The model answers the one part a string match cannot: does
any segment execute a construction type the contract forbids, however it is
worded? Each finding names the rule id and its tier, because the tier decides
the route: a tier-2 rule sends the destination back to S-08, and a tier-1 hard
platform rule with no compliant variant ends the destination.

## Enforces
Map §9.1 V-P04, and the tier order of map §5: a client rule can be replanned
around, a hard platform rule cannot be published against.
