# Portfolio pressure was taken into account

## Rule
A plan that repeats the portfolio's recent shape — the same reader path, the
same opening move, the same ending on the same destination — is worth noticing.
It is never a reason to block, edit or replan anything.

## Criterion
Code compares the plan's fields with the fingerprints of this client's recent
publications on this destination and records what it found: which fields repeat,
how recently, and over how many publications. No threshold decides anything
(I-12); the comparison is carried as a hint and as the tier-5 tie-breaker S-09
may use between candidates that are already admissible.

## Enforces
Nothing. Map §9.1 calls it a soft signal, and map §10 makes portfolio influence
soft pressure rather than a quota.
