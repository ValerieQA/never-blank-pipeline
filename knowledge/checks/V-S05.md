# How close this text is to the portfolio

## Rule
Similarity to what this client has already published — the same reader path,
the same opening, the same ending, shared n-grams — is worth recording. It is
never a reason to block, edit or replan anything.

## Criterion
Code compares the text and its fingerprint fields with the prior fingerprints of
this client: path, opening, ending, and n-gram overlap, each reported
separately so that a shared path and a shared phrasing are not added together
into one number nobody can act on. Near-exact republication is not this check's
business — that is V-T05, which is hard and does block.

## Enforces
Nothing here. It is the soft half of map §10: memory presses, it does not
forbid. S-09 may use the comparison as the tier-5 portfolio tie-breaker between
candidates that are already admissible.
