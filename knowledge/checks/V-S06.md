# The anti-template test

## Rule
If the material label predicts the rest of a text's fields, the label has become
a template. That is worth reporting. It is never a reason to block, edit or
replan anything.

## Criterion
Code runs over fingerprints, after the run, and measures how well the label
predicts the strategy fields: opening, reveal, concession, ending. High
predictability means the label is doing the deciding. The measurement is a
report to the keeper.

This check is computed **outside** S-00…S-13 and reads label records, which is
the one place a label may be read at all. No stage consumes it, and its result
never reaches a run (AD-07, I-10). A missing label is missing data, not a zero.

## Enforces
Nothing. Map §7 point 5 and §9.2 V-S06: the label names a description, and the
day it starts predicting the text it has stopped being a name.
