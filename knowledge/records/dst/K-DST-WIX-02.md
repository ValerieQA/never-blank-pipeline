# An adjacent question gets its own section, because search splits the query

## Statement
Vendor data holds that a search engine answering a question splits it into
sub-questions and cites the page that answers each one. An article that gives
each adjacent question its own section, with a subheading that states that
section's own answer, is citable for each of them; the same material written as
one undivided argument is citable for none.

## Applies when
destination is wix

## Influences
- S-10 · `E-14.subheadings` — an adjacent question becomes its own subheading,
  stating that section's answer.
- S-10 · `E-14.segments` — one sub-question per section.

## Conflicts
`K-DST-WIX-01` shapes how a subheading is worded and this record shapes which
sections exist; they point the same way and neither decides the other's half.
Where the client contract fixes the article's frame, the contract is tier 2 and
wins.
